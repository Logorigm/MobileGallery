# Offline Media Vault

Личное хранилище фото, видео, GIF и манги (PDF) для Android. Всё лежит только на телефоне:
у приложения **нет доступа в интернет** (разрешение INTERNET вырезано даже из библиотек),
нет рекламы, аккаунтов и облака.

Версия **3.0** · Android 6.0+ (minSdk 23, targetSdk 35) · 8 языков: English, Русский, Español,
فارسی, Deutsch, Français, 中文, 日本語.

---

## Возможности

### Лента и сетка (как в Google Фото)
- Сетка показывает только видимые плитки — тысячи файлов листаются без тормозов.
- Заголовки по дням: «Сегодня», «Вчера», «пн, 6 октября»… (можно выключить в настройках).
- **Щипок двумя пальцами** меняет число колонок (1–6).
- **Зажмите плитку и протяните** — выделится сразу диапазон; нажатие на заголовок дня выделяет весь день.
- Бегунок быстрой прокрутки справа с подписью даты.
- Свайп плитки вправо — быстрые теги.
- Фильтр: теги, «чёрные» теги, совпадение «все / любой», избранное, тип файла, сортировка (новые, старые, случайно).
- «Продолжить просмотр» — последний открытый файл с позицией видео или страницей манги.
- Миниатюры кэшируются на диске, длительность видео и число страниц PDF видны сразу.

### Клипы — вертикальная лента на весь экран (как TikTok / Reels / Shorts)
- Листайте вверх — следующий файл; видео запускаются сами и крутятся по кругу.
- Двойное касание — в избранное (с летящим сердцем), удержание — ускорение ×2, касание — пауза.
- Кнопки: избранное, теги, поделиться, открыть в полном просмотре; звук вкл/выкл.
- Открываются из ленты (с текущим фильтром) и из любого альбома или подборки.

### Просмотр
- Листание свайпом, щипок и двойное касание для увеличения, свайп вниз — закрыть, свайп вверх — сведения.
- Свой видеоплеер: перемотка, скорость, двойное касание ±10 с, запоминание позиции.
- GIF и анимированный WebP оживают (Android 9+).
- **Слайд-шоу**: фото каждые 4 с, видео до конца; любое касание останавливает.
- Манга (PDF): слева направо, справа налево или вертикальной лентой.
- Поворот, теги, альбомы, переименование, «Поделиться», «Сохранить в галерею».

### Поиск по всему
- Имена, теги, альбомы, типы («видео», «gif») и месяцы («октябрь 2025»).
- `#тег` — точный тег, `-слово` — исключить. Подсказки тегов на лету, недавние запросы.

### Альбомы, подборки и теги
- Альбомы с ручным порядком; файл может лежать в нескольких альбомах.
- Умные подборки: недавно добавленные, фото, видео, GIF, манга/PDF, без тегов, зашифрованные.
- Менеджер тегов: показать файлы, переименовать / объединить, скрыть в ленте, удалить отовсюду.
- Автотеги на устройстве (ML Kit) — учатся на ваших собственных тегах.

### Обмен файлами
- **Поделиться** в любое приложение (зашифрованные файлы расшифровываются во временную папку, она чистится через час).
- **Сохранить в галерею** телефона: «Изображения / Фильмы / Загрузки → Offline Media Vault».
- **Принять из других приложений**: в галерее, браузере или мессенджере выберите «Поделиться → В хранилище».
- Импорт ZIP (архив становится альбомом), экспорт всей библиотеки или выбранных файлов в ZIP
  вместе с тегами, альбомами и избранным.

### Защита
- PIN-код, который проверяется сам по мере ввода; разблокировка **по отпечатку / лицу** (Android 9+).
- Блокировка после выхода: сразу, через 30 с, 1 мин или 5 мин.
- «Ложный» PIN открывает пустое хранилище.
- Шифрование файлов AES-256 + HMAC (ключ в Android Keystore), проверка целостности.
- Запрет скриншотов и скрытие содержимого в списке недавних.

### Остальное
- Корзина с автоочисткой (7–90 дней) и «Отменить» после удаления.
- Поиск дубликатов, статистика библиотеки, отчёт о сбоях.
- 12 тем + системная, 5 шрифтов, фон-обои, 15 иконок (сезонные и праздничные сами меняются по дате),
  своё название и иконка ярлыка, ярлыки «Загрузка» и «Избранное».
- Окно «Что нового» после обновления.

## Как установить

### Готовый APK (проще всего)
1. Откройте вкладку **Actions** репозитория → последняя успешная сборка **Build APK**.
2. Внизу, в разделе **Artifacts**, скачайте `OfflineMediaVault-release-apk`.
3. Распакуйте ZIP и установите `OfflineMediaVault-<версия>.apk` на телефон
   (разрешите установку из этого источника, если Android спросит).

Если в репозитории создан тег вида `v3.0`, тот же APK появляется и на странице **Releases**.

> Обновление ставится поверх старой версии **без потери данных**: все сборки подписаны одним ключом
> (`app/debug.keystore`). Файлы лежат во внутренней папке приложения — при **удалении** приложения
> Android удалит и их, поэтому перед удалением сделайте «Экспорт всей библиотеки» в настройках.

### Собрать самому в Android Studio
1. Установите [Android Studio](https://developer.android.com/studio) и откройте папку проекта (**Open**).
2. Дождитесь синхронизации Gradle (при запросе установите Android SDK Platform 35).
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**. APK: `app/build/outputs/apk/debug/app-debug.apk`.

### Собрать из терминала
При установленных JDK 17, Gradle 8.9 и Android SDK:

```
gradle assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

Скрипты в `tools/` скачивают переносные JDK 17, Gradle 8.9 и Android SDK в `tools/portable/`:

- Windows (PowerShell): `Set-ExecutionPolicy -Scope Process Bypass`, затем `./tools/setup-windows.ps1`
- Linux / macOS: `chmod +x tools/setup-linux-macos.sh && ./tools/setup-linux-macos.sh`

После установки скрипт покажет готовую команду сборки.

## Устройство проекта

| Файл | Что внутри |
|---|---|
| `MainActivity.java` | весь интерфейс: вкладки, сетка на RecyclerView, просмотр, Клипы, поиск, настройки, блокировка |
| `Library.java` | библиотека: `files/media` + `library.json` (атомарная запись с резервной копией), альбомы, корзина, умные подборки |
| `Crypto.java` | шифрование файлов (AES-CTR + HMAC-SHA256, ключ обёрнут Android Keystore) |
| `ShareProvider.java` | выдача файлов другим приложениям по временным `content://`-ссылкам |
| `AutoTagger.java`, `Personal.java`, `Labels.java` | автотеги ML Kit и подсказки по вашим тегам |
| `IconPlan.java`, `IconJobService.java` | сезонные и праздничные иконки |
| `Strings.java` | все тексты интерфейса на 8 языках |
| `ZoomImageView.java` | увеличение фото и страниц манги |

Формат хранения совместим со всеми прошлыми версиями: при первом запуске новая версия сама
подхватывает старые данные.

## История версий

- **3.0** — Клипы (вертикальная лента), поиск по всему, сетка как в Google Фото (дни, щипок, выделение
  протягиванием, бегунок), кэш миниатюр, «Поделиться» / «Сохранить в галерею» / приём из других приложений,
  слайд-шоу, живые GIF, отпечаток пальца, задержка блокировки, умные подборки, менеджер тегов, «Что нового».
- **2.2** — строгий «галерейный» дизайн, свои иконки, выбор шрифта, новый просмотр со свайпом, свой плеер, поворот.
- **2.1** — визуальное обновление: шрифт Inter, векторные иконки, стеклянные карточки, edge-to-edge.
- **2.0** — release-сборка, анимации, haptics, «Отменить», отчёт о сбоях.
- **1.9** — шифрование файлов, проверка целостности, своё название и иконка, личные автотеги.
- **1.8** — автотеги ML Kit, быстрые теги, праздничные иконки, обои, скорость видео.
- **1.7** — избранное, режимы манги, ложный PIN, статистика, дубликаты, ручной порядок.
- **1.4–1.6** — альбомы, корзина, PIN, манга PDF, языки, выбор иконки.
